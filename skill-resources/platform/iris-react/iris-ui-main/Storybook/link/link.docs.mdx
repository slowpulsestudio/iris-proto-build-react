# Link

`iris-link` renders a single anchor element. It uses `text` for the visible label when provided; otherwise it falls back to `href`. The component supports two sizes (`default` and `lg`), forwards `target` directly to the anchor, and does not provide router-link behaviour.

## Disabled

When `disabled` is `true`, the component removes `href`, applies `aria-disabled="true"`, and sets `tabindex="-1"`.

<Canvas of={LinkStories.Disabled} />

## Target handling

`target` is forwarded as-is to the underlying anchor. Setting `target="_blank"` does not add `rel` or any extra "opens in new tab" text automatically.

## Visited

The component renders a normal anchor, so any visited styling depends on the browser and the linked URL.

<Canvas of={LinkStories.Visited} />

## Accessibility

- Provide descriptive `text`, because the component does not add hidden helper text.
- If you open a link in a new tab, include that information in the visible label yourself when users need the warning.
- Disabled links are removed from the tab order.
- The component does not add custom keyboard behaviour beyond native anchor behaviour.
