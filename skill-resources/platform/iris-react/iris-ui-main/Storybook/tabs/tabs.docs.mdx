# Tabs

`iris-tabs` renders a tab strip from an `items` array and reports the selected tab through `activeValueChange`. It only renders the tabs themselves; your application owns the active panel content and any panel ARIA relationships.

Each item requires a `label` and `value`, and can optionally add an icon plus a counter. `counterType="action"` renders the counter as a badge; omitted `counterType` renders the count in parentheses.

## Counters

Tab items accept an optional `counter` number. Use `counterType: 'default'` (or omit it) for an informational count shown in parentheses. Use `counterType: 'action'` for a highlighted badge.

## Accessibility

- The tab list uses `role="tablist"`, and each tab button uses `role="tab"` with `aria-selected`.
- Supply an `ariaLabel` input to label the tablist when multiple tablists exist on the same page (WCAG 4.1.2).
- Icons are rendered with `aria-hidden="true"` so only the tab label text contributes to the accessible name.
- Keyboard support: Arrow Left/Right cycle tabs; Home moves to first tab; End moves to last tab.
- The component does not render `role="tabpanel"`, `aria-controls`, `aria-labelledby`, or disabled tabs.

## Events

`activeValueChange` emits the selected tab's `value` whenever a tab is clicked or activated through the native button interaction.

### TabItem

Each object in the `items` array must conform to the `TabItem` interface.

| Property      | Type                    | Required | Description |
| ------------- | ----------------------- | -------- | ----------- |
| `label`       | `string`                | ✓        | Visible text for the tab and the primary accessible name. |
| `value`       | `string`                | ✓        | Unique identifier used for selection and emitted through `activeValueChange`. |
| `icon`        | `string`                | —        | Optional icon rendered before the label. |
| `counter`     | `number`                | —        | Optional count rendered after the label when provided. |
| `counterType` | `'default' \| 'action'` | —        | `action` renders a highlighted badge. Any other value, or omission, renders the count in parentheses. |
