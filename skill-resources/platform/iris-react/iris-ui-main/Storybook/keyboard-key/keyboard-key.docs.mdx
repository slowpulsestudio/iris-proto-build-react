# Keyboard Key

`iris-keyboard-key` is a presentational shortcut label. Pass a single string to render one key, or an array of strings to render a combination separated by visible `+` characters. The `type` input currently accepts only `'default'` and does not change the rendered output.

## Label formatting

- Single-character labels are uppercased.
- Longer labels are normalised to first-letter uppercase and remaining letters lowercase.

### Key combination

When `key` is an array, the component renders one key cap per item and inserts visible `+` separators between them.

<Canvas of={KeyboardKeyStories.Combination} />

## Accessibility

- The component renders semantic `<kbd>` elements only.
- It does not add ARIA attributes or keyboard handlers.
- Shortcut descriptions such as "Open command palette" still need to come from surrounding copy or an enclosing accessible label.
