# Radio Buttons

Use `iris-radio-group` with one or more `iris-radio-button` children when the user must choose exactly one option. The group owns the selected value, applies the shared size, and can be bound as an Angular form control. Each button contributes its own required `value`, projected label content, optional `supportingText`, and optional per-option `disabled` state.

## Forms

`iris-radio-group` implements `ControlValueAccessor`, so it can be used with `formControl` or `formControlName`. User selection updates the form value and emits `selectionChange`. Programmatic writes through the form update the selected option without emitting `selectionChange`.

## Accessibility

- The group host renders with `role="radiogroup"` and `aria-disabled`.
- Supply a group label via `ariaLabel`; it maps to `aria-label` on the group host. Alternatively, associate a visible label element in your page markup using `aria-labelledby`.
- Each radio host renders with `role="radio"`, `aria-checked`, `aria-disabled`, and `tabindex="0"` while enabled.
- Keyboard support is limited to `Tab` for focus movement and `Space` for selection. Arrow-key navigation is not implemented.
