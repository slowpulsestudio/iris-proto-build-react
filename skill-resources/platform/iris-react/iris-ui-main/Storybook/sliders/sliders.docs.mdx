# Slider

`iris-sliders` supports two modes: a single value slider (`dualThumb = false`) and a range slider (`dualThumb = true`). In both modes the component is driven by numeric inputs and emits the updated numeric values through outputs rather than Angular forms APIs.

`label` is independent of thumb mode. Use `tooltip` (default) to show values only while a thumb is focused or being dragged, `bottom` to keep values visible below the thumb, or `none` to hide the value label entirely.

## Accessibility

- Each thumb is a native `input[type="range"]`, so browsers provide the default range keyboard behaviour for the focused input.
- The component binds `aria-valuemin`, `aria-valuemax`, and `aria-valuenow` to each rendered range input.
- In dual-thumb mode, each thumb gets an accessible name via `minimumValueAriaLabel` (default `'Minimum value'`) and `maximumValueAriaLabel` (default `'Maximum value'`). Localise these for non-English UIs.
- The single-thumb input has no `aria-label` by default; wrap the component in a `<label>` or use `aria-labelledby` at the host level to provide an accessible name.
- The component does not implement `ControlValueAccessor`; integrate it through `value`/`valueChange` or `valueLow`/`valueLowChange`/`valueHigh`/`valueHighChange`.
