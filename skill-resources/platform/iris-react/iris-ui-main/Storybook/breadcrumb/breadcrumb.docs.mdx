# Breadcrumb

Shows a navigation path as an ordered list of links and text, with the last item treated as the current page. When the path is too long, intermediate items can be collapsed into an overflow menu that reveals the hidden levels on click.

## Overflow

When `maxVisibleItems` is set and the path exceeds that limit, middle items collapse behind a `…` button. Clicking the button opens a dropdown listing the hidden breadcrumb levels.

<Canvas of={BreadcrumbStories.Overflow} />

## Behaviour notes

- Separators are always rendered as `/`.
- Items use plain `href` links when `href` is provided.
- The last item renders as plain text by default, even if it has an `href`.
- Set `currentPageClickable` to `true` if the last item should stay clickable when it has an `href`.

## Accessibility

- The breadcrumb is wrapped in `<nav>` with an accessible label. The label defaults to `"Breadcrumb"`; override `ariaLabel` when a page has multiple navigation landmarks or when a localised label is needed.
- The current page is announced with `aria-current="page"`.
- Separator characters are marked `aria-hidden="true"` so they are not announced as part of the navigation text.
- The overflow button has an accessible label ("Show more breadcrumb items") and exposes `aria-haspopup` and `aria-expanded` states.

### BreadcrumbItem

Each object in the `items` array must conform to the `BreadcrumbItem` interface.

| Property | Type | Required | Description |
|---|---|---|---|
| `label` | `string` | ✓ | Text shown for the breadcrumb item. |
| `href` | `string` | — | Optional plain link target. If omitted, the item renders as non-interactive text. |
