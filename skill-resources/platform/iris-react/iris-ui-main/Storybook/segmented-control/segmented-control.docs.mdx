# Segmented Control

`iris-segmented-control` renders a mutually exclusive set of button-like options. Supply the options through `items`, bind the selected option through `activeValue`, and choose one display mode for the entire control with `type`: `icon-only` (default), `icon-text`, or `text-only`.

In `icon-only` mode, items with an icon hide their visible label and use the label for both the tooltip text and the accessible name. If an item has no icon, the text label is shown even in `icon-only` mode.

## With Reactive Forms

`iris-segmented-control` implements `ControlValueAccessor`, so it can be bound with `formControl` or `formControlName`. When used inside `iris-form-field`, it also exposes invalid, touched, required, and disabled state through the `IrisFormControl` token.

Keyboard focus marks the control as touched. Mouse focus alone does not; the control is marked touched after a user selection.

## Accessibility

- The container renders with `role="tablist"`; each segment is a native `button` with `role="tab"` and `aria-selected`.
- In `icon-only` mode, items with an icon receive `aria-label` from the item label.
- Disabled state is applied through the native `disabled` attribute on every segment button.
- Keyboard support relies on native button behaviour: `Tab` moves between segments and `Enter`/`Space` activates the focused segment. Arrow-key navigation is not implemented.
- The component does not generate tab panels, `aria-controls`, or `aria-labelledby` relationships.

### SegmentedControlItem

Each object in the `items` array must conform to the `SegmentedControlItem` interface.

| Property   | Type     | Required | Description |
| ---------- | -------- | -------- | ----------- |
| `label`    | `string` | ✓        | Visible label in `text-only` mode, visible label in `icon-text` mode, and tooltip/accessibility label in `icon-only` mode when an icon is present. |
| `value`    | `string` | ✓        | Unique value emitted through `activeValueChange` and written through forms integration. |
| `iconName` | `string` | —        | Optional icon rendered in `icon-only` and `icon-text` modes. When omitted, the label stays visible. |
