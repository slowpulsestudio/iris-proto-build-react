# Badge

A compact, non-interactive label for status or category text, with optional leading icon.

## When to use

| Type | Use when |
|---|---|
| **Default** | Neutral information or general categorisation |
| **Info** | Informational state |
| **Success** | Positive or completed state |
| **Error** | Failure or critical state |
| **Warning** | Caution or attention-needed state |

## Behaviour notes

- `text` is rendered inline inside the badge.
- `iconName` adds a leading icon.
- If `text` is empty, the badge can render as icon-only.
- The component does not provide count formatting, `max`, or dot-only presentation.

## Accessibility

- The icon is decorative; it is rendered with an empty icon label.
- Accessible text comes from `text`, so keep that value short and explicit.
- Avoid icon-only badges when the meaning must be announced to assistive technology.
