# Dropdown

A trigger-and-panel pattern that lets users pick a single value from a vertically stacked list of options. Supports keyboard navigation, default and large sizes, disabled and error states, and an optional leading icon. Compose it inside `iris-form-field` together with `iris-label` and optionally `iris-subtext` for label and validation text.

## Using without Form Field

`iris-dropdown` can be used standalone — without `iris-form-field`, `iris-label`, or `iris-subtext` — when
label and feedback are handled externally or are not needed (e.g. inline filters, toolbar selectors,
or custom layout compositions).

## Disabled state

Apply the `disabled` input or call `formControl.disable()` to prevent interaction. Both sources are resolved together — the dropdown is disabled when either is true. Ensure there is always another way to reach the action.

<Canvas of={DropdownStories.Disabled} />

## Validation error

Connect the dropdown to a reactive form control. Declare individual `iris-subtext type="error"` elements
with `@if` conditions. When the control is invalid and touched, `iris-form-field` automatically
shows only the first matching error and hides the hint.

## Accessibility

- The trigger has `role="combobox"` with `aria-expanded`, `aria-haspopup="listbox"`, and when the panel is open, `aria-controls` referencing the listbox.
- When bound to a form control with `Validators.required`, `aria-required` is set on the trigger.
- When the control is invalid and touched, `aria-invalid` is set on the trigger.
- **ArrowDown** opens the panel when it is closed; when open, **ArrowDown / ArrowUp** move focus through options.
- **Home / End** jump to the first and last focusable option.
- **Enter** or **Space** selects the focused option and closes the panel.
- **Escape** closes the panel and returns focus to the trigger.
- Typing a printable character moves focus to the first option whose label starts with that character (typeahead).
- **Tab** or clicking outside closes the panel and marks the control as touched.

### DropdownOption fields

| Property | Type | Required | Description |
|---|---|---|---|
| `type` | `'item'` | ✓ | Identifies this entry as a selectable row. |
| `label` | `string` | ✓ | Display text shown in the option row. |
| `value` | `string` | ✓ | Value emitted on selection and stored as the current selection. |
| `icon` | `string` | — | Icon name rendered to the left of the label. |
| `disabled` | `boolean` | — | When `true`, the option is non-interactive and visually dimmed. |
