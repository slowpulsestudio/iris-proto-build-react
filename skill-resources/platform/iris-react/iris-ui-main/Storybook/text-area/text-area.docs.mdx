# Text Area

A multi-line text field built on a native `<textarea>`. It works best inside `iris-form-field` together with `iris-label` and optional `iris-subtext`, because the wrapper supplies label, hint, error, required-indicator, and counter presentation.

Current implementation exposes `placeholder`, `value`, `disabled`, and `readonly`. It does not expose `rows` or `resize` inputs.

## Validation error

Connect textarea to reactive form control. Error styling appears only when bound control is both invalid and touched. Declare individual `iris-subtext type="error"` elements with `@if` conditions. `iris-form-field` shows first matching error and hides hint text.

## Character count

Add `Validators.maxLength(n)` to bound form control. Current character count comes from textarea value, and maximum comes from validator metadata. In current implementation, same validator also sets native `maxlength` attribute on textarea.

<Canvas of={TextAreaStories.WithCharacterCount} />

## Accessibility

- `iris-label` provides label association when composed inside `iris-form-field`.
- Native textarea keyboard behaviour is preserved; component adds no custom shortcuts.
- `aria-invalid` is set only when attached form control exists and is both invalid and touched.
- Readonly textareas stay focusable. Disabled textareas do not.
