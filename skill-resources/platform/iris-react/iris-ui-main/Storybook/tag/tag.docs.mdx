# Tag

`iris-tag` renders a text label with an optional remove action. The component is consumer-controlled: activating the remove affordance emits `removed`, but your application decides whether the tag actually disappears.

`text` supplies the visible label. `removable` defaults to `true`; when set to `false`, only the focusable text remains.

## Accessibility

- When present, the remove button label defaults to `"Remove"`. Override `removeAriaLabel` to localise it.
- Clicking the remove button emits `removed` and stops the click from bubbling to ancestors.
- Pressing `Enter` or `Space` on the remove button emits `removed`.
