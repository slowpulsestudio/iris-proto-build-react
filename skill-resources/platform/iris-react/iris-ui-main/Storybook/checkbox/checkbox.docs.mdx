## Behaviour notes

- Clicking anywhere on the checkbox row calls the same toggle logic.
- Pressing `Space` toggles the checkbox and prevents page scrolling.
- If `indeterminate` is `true`, the next user toggle clears indeterminate and sets the checkbox to unchecked.
- The component implements `ControlValueAccessor` and reads or writes boolean values through Angular forms.
- Form writes update `checked` only; indeterminate state is controlled separately.

## Accessibility

- The root element uses `role="checkbox"` and `aria-label` from `label`.
- When `indeterminate` is true, the component sets `aria-checked="mixed"`.
- `supportingText` is visual only; it is not connected with `aria-describedby`.
- Disabled state is exposed with `aria-disabled`, and toggle logic is blocked.
- Current implementation keeps `tabindex="0"` even when disabled, so disabled checkboxes remain focusable.
