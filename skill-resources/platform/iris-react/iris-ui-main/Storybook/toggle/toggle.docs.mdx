# Toggle

A binary switch for immediate on / off changes. Current implementation renders only switch control itself; consumers must supply visible label text outside component.

## Interactive Demo

Off and on states shown side by side. Toggle `disabled` control to apply same interaction lock to both.

## Disabled state

Apply `disabled` to prevent interaction. Angular forms can also disable control through `ControlValueAccessor`.

## Forms integration

`iris-toggle` implements `ControlValueAccessor`, so it works with reactive forms, `formControlName`, and `ngModel`. Toggling updates form value immediately and marks control as touched.

## Accessibility

- Toggle renders native `<button type="button">` with `role="switch"`.
- `aria-checked` reflects current boolean state.
- Enter and Space activation come from native button behaviour; component adds no custom key handlers.
- Disabled state is represented by native `disabled` attribute on button. Current implementation does not add `aria-disabled` or `aria-required`.
- Provide visible label outside component so switch purpose is clear.
