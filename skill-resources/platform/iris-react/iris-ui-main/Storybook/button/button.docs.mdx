# Button

Triggers an action with one of four visual variants and optional icon support.

## When to use

| Variant | Use when |
|---|---|
| **Primary** | Main call-to-action |
| **Secondary** | Supporting action alongside a primary action |
| **Ghost** | Low-emphasis or inline action |
| **Danger** | Destructive or irreversible action |

## Behaviour notes

- Button text is projected content, not a `label` input.
- `buttonType="text-only"` renders label text only.
- `buttonType="icon-text"` renders icon and label when `iconName` is provided.
- `buttonType="icon-only"` hides the projected label visually but keeps it in the DOM for accessibility.
- The component does not provide built-in loading, full-width, or menu-trigger states.

## Accessibility

- The component relies on native button semantics for focus and keyboard activation.
- Project meaningful text content for all button types — it is always the accessible name.
- For `icon-only` buttons the projected text is hidden visually but announced by screen readers.
- `type` defaults to `"button"`; set `type="submit"` when the button should submit a form.
