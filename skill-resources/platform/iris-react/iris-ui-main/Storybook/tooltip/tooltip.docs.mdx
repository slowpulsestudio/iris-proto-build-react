# Tooltip

Attaches short informational text to an existing element through directive API. Tooltip appears in CDK overlay on hover or focus and is removed from DOM again when pointer leaves or focus moves away.

Current implementation accepts plain string text, optional shortcut key labels, and one requested placement. It does not support template content, delays, or Escape-key dismissal.

## Accessibility

- Tooltip surface uses `role="tooltip"`.
- Directive sets `aria-describedby` on trigger element only while tooltip is visible, then removes it on hide.
- Tooltips open on both `mouseenter` and `focusin`, so keyboard users can reveal them.
- Current implementation closes on `mouseleave` and `focusout`. It does not add Escape-key handling.
- Keep tooltip text brief and supplemental; it should not replace visible label.
