# Sidesheet

A panel that slides in from the right edge of the screen to display supplementary content without navigating away from the current page. The sidesheet is opened exclusively via `IrisSidesheetService.open()` — there is no template declaration. It always renders as an overlay with a dimmed backdrop, and slides out with a CSS animation on close.

The header shows a title, an optional subtitle, and an optional icon. Dismiss behaviour is controlled per-instance: the × button, Escape key, and backdrop click can each be enabled or disabled independently. An optional maximize toggle expands the panel to fill the full viewport width.

Arbitrary content is injected into the body by passing a component type to `IrisSidesheetService.open()`. Data flows into the content component via the `IRIS_SIDESHEET_DATA` injection token (use `injectSheetData<T>()`). The content component receives an `IrisSidesheetRef` to close the panel and pass a typed result back to the caller via `afterClosed()`.

## Usage

Define the component you want to render inside the sidesheet, then open it via `IrisSidesheetService`.

```ts
// my-details.component.ts
import { Component, inject } from '@angular/core';
import { IrisButtonComponent } from '@one-identity/iris/button';
import { IrisSidesheetContent, IrisSidesheetRef, injectSheetData, irisSidesheetFooterDirective } from '@one-identity/iris/sidesheet';

export interface MyDetailsData {
  itemId: number;
}

@Component({
  standalone: true,
  imports: [IrisButtonComponent, irisSidesheetFooterDirective],
  template: `
    <p>Showing details for item #{{ sidesheetData.itemId }}</p>
    <ng-template irisSidesheetFooter>
      <iris-button variant="secondary" (click)="sheetRef.close()">Cancel</iris-button>
      <iris-button (click)="sheetRef.close(true)">Save</iris-button>
    </ng-template>
  `,
})
export class MyDetailsComponent implements IrisSidesheetContent<MyDetailsData> {
  readonly sidesheetData = injectSheetData<MyDetailsData>();
  readonly sheetRef = inject(IrisSidesheetRef<boolean>);
}
```

```ts
// parent.component.ts
import { Component, inject } from '@angular/core';
import { IrisSidesheetService } from '@one-identity/iris/sidesheet';
import { MyDetailsComponent } from './my-details.component';

@Component({
  standalone: true,
  template: `<button (click)="open()">Open details</button>`,
})
export class ParentComponent {
  private readonly sheetService = inject(IrisSidesheetService);

  open(): void {
    const ref = this.sheetService.open(MyDetailsComponent, {
      title: 'Item Details',
      subtitle: 'Review and confirm',
      data: { itemId: 42 },
    });

    ref.afterClosed().subscribe((saved) => {
      if (saved) {
        // handle confirmed result
      }
    });
  }
}
```

## Typing options

`IrisSidesheetService.open()` supports four combinations of typed data and typed result. Both are opt-in — use only what you need.

### Typed data

Implement `IrisSidesheetContent<D>` on the content component and assign `injectSheetData<D>()` to `sidesheetData`. The `data` field in `IrisSidesheetConfig` is then compile-time checked against `D`.

```ts
// content component opts in to typed data
class MyComponent implements IrisSidesheetContent<{ itemId: number }> {
  readonly sidesheetData = injectSheetData<{ itemId: number }>();
}

sheetService.open(MyComponent, { data: { itemId: 42 } }); // ✅
sheetService.open(MyComponent, { data: 'wrong' });          // ❌ compile error
```

Components that do not implement `IrisSidesheetContent` accept any value (or none) for `data`.

### Typed result

Pass `R` as an explicit type argument to `open<R>()` to type the value emitted by `afterClosed()`. The content component calls `sheetRef.close(value)` with a matching type.

```ts
// content component
class ConfirmComponent {
  readonly sheetRef = inject(IrisSidesheetRef<boolean>);
  confirm() { this.sheetRef.close(true); }
  cancel()  { this.sheetRef.close(false); }
}

// caller
const ref = sheetService.open<boolean>(ConfirmComponent, { title: 'Confirm?' });
ref.afterClosed().subscribe((confirmed: boolean) => { ... });
```

Omit the type argument to leave the result as `unknown`.

### All four combinations

| Data typed | Result typed | Call |
|---|---|---|
| ✅ | ✅ | `open<boolean>(MyComponent, { data: { itemId: 42 } })` |
| ✅ | — | `open(MyComponent, { data: { itemId: 42 } })` |
| — | ✅ | `open<boolean>(SimpleComponent, { title: '...' })` |
| — | — | `open(SimpleComponent, { title: '...' })` |

## With Footer Alignment

Add a footer by placing `<ng-template irisSidesheetFooter>` inside your content component. Import `irisSidesheetFooterDirective` in the component's `imports` array. Control alignment via `footerAlign` in `IrisSidesheetConfig` (`'start'` | `'center'` | `'end'`, defaults to `'end'`).

```ts
@Component({
  imports: [irisSidesheetFooterDirective, IrisButtonComponent],
  template: `
    <p>Body content</p>
    <ng-template irisSidesheetFooter>
      <iris-button variant="secondary" (click)="sheetRef.close()">Cancel</iris-button>
      <iris-button (click)="sheetRef.close(true)">Save</iris-button>
    </ng-template>
  `,
})
export class MySheetContent {
  readonly sheetRef = inject(IrisSidesheetRef<boolean>);
}
```

## Accessibility

- The panel renders as `<aside role="dialog" aria-modal="true">`. `aria-label` is set from `title`.
- Focus is trapped inside the panel when open and restored to the element that triggered the open on close.
- Pressing Escape closes the panel when both `dismissable` and `closeOnEscape` are `true`.
- The maximize button exposes `aria-pressed` plus state-specific labels. Override `maximizeAriaLabel` and `restoreAriaLabel` to localise them.
- The close button label defaults to `"Close"`. Override `closeAriaLabel` to localise it.

## API

### IrisSidesheetConfig

| Property | Type | Default | Notes |
|---|---|---|---|
| `data` | `unknown` | `null` | Injected into the content component via `IRIS_SIDESHEET_DATA`. Type is inferred from the component's `IrisSidesheetContent<D>` implementation when used via the service. |
| `title` | `string` | `''` | Written to the header title. |
| `titleIcon` | `string` | `''` | Renders an icon before the title when non-empty. |
| `subtitle` | `string` | `''` | Adds subtitle text below the title. |
| `width` | `string` | `'512px'` | Any valid CSS length. |
| `dismissable` | `boolean` | `true` | Master gate: hides × button and disables Escape and backdrop-click when `false`. |
| `closeAriaLabel` | `string` | `'Close'` | Accessible label for the × close button. Localise for non-English UIs. |
| `closeOnEscape` | `boolean` | `true` | Used only when `dismissable` is `true`. |
| `closeOnBackdropClick` | `boolean` | `true` | Used only when `dismissable` is `true`. |
| `enableMaximizeToggle` | `boolean` | `false` | Shows a maximize toggle button in the header. |
| `maximizeAriaLabel` | `string` | `'Maximize'` | Accessible label for the maximize button. Localise for non-English UIs. |
| `maximized` | `boolean` | `false` | Opens the panel already expanded to full viewport width. |
| `footerAlign` | `'start' \| 'center' \| 'end'` | `'end'` | Controls footer action alignment. |
| `restoreAriaLabel` | `string` | `'Restore'` | Accessible label for the restore button. Localise for non-English UIs. |

### IrisSidesheetRef\<R\>

Returned by `IrisSidesheetService.open()`. `R` is the type of the value passed to `close()`.

| Member | Signature | Notes |
|---|---|---|
| `afterClosed()` | `() => Observable<R>` | Emits once with the value passed to `close()`, then completes. Use `firstValueFrom(ref.afterClosed())` for a Promise. |
| `close()` | `(data?: R) => void` | Closes the sidesheet and emits `data` via `afterClosed()`. Call from the content component via `inject(IrisSidesheetRef)`. |
