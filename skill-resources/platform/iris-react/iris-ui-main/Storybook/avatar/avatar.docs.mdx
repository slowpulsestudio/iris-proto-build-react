# Avatar

Displays either a profile image or a text placeholder inside a circular avatar.

## When to use

| Type | Use when |
|---|---|
| **Placeholder** | You want to show initials instead of a photo |
| **Face** | You have an image URL and want to render a profile photo |

## Face

Use `type="face"` together with `src` to render an `<img>`.

<Canvas of={AvatarStories.Face} />

## Behaviour notes

- `type="placeholder"` renders the `initials` string.
- `type="face"` renders an image only when `src` is non-empty.
- If `type="face"` is used without `src`, the avatar renders an empty container.
- The component has no built-in fallback when an image fails to load.

## Accessibility

- The outer avatar container sets its accessible name from `alt` first, then falls back to `initials`.
- In face mode, the inner `<img>` also receives the `alt` value.
- Placeholder avatars do not add focus or button semantics; wrap them in another interactive element if they need to be clickable.
