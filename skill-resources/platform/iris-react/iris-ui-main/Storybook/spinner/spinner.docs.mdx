# Spinner

`iris-spinner` renders a non-interactive SVG loading indicator. Use `scenario="loop"` for indeterminate loading and `scenario="completion"` when you have a numeric percentage to visualize.

In completion mode, `progress` is clamped to `0–100`, with values from `91` to `99` reduced to `90`. Only a literal `100` produces a closed circle.

## When to use

| Scenario       | Use when |
| -------------- | -------- |
| **Loop**       | The duration or completion percentage of the operation is not known. |
| **Completion** | You have a numeric percentage and want the arc length to reflect it visually. |

## Accessibility

- The host element renders with `role="status"` and an accessible label. The label defaults to `"Loading"`; override `ariaLabel` to localise it or provide context-specific text (e.g. `"Saving changes…"`).
- The inner SVG is `aria-hidden="true"` to avoid double-announcement.
- The component does not expose a textual percentage announcement in completion mode.
