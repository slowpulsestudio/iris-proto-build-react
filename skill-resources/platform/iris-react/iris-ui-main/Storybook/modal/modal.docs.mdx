# Modal

`iris-modal` wraps native `<dialog>` behaviour in a component API. Call `open()` to show it and `close(data?)` to start closing it. The component owns its open state internally and emits `(closed)` after the close sequence finishes.

## Usage

The modal supports two approaches.

### Service approach

Use `IrisModalService.open()` when the modal body is a separate component or when you want an `IrisModalRef` back.

Define a content component. Implement `IrisModalContent<D>` and assign `injectModalData<D>()` to `modalData` to receive typed data. Use `IrisModalRef<R>` to close with a typed result. Add footer actions via `<ng-template irisModalFooter>` — import `IrisModalFooterDirective` in the component:

```ts
// confirm-modal.component.ts
@Component({
  selector: 'app-confirm-modal',
  imports: [IrisModalFooterDirective, IrisButtonComponent],
  template: `
    <p>{{ modalData.message }}</p>
    <ng-template irisModalFooter>
      <iris-button variant="secondary" (click)="modalRef.close()">Cancel</iris-button>
      <iris-button (click)="modalRef.close(true)">Confirm</iris-button>
    </ng-template>
  `,
})
export class ConfirmModalComponent implements IrisModalContent<{ message: string }> {
  readonly modalData = injectModalData<{ message: string }>();
  readonly modalRef = inject(IrisModalRef<boolean>);
}
```

Open it and react to the result:

```ts
const ref = this.modal.open<boolean>(ConfirmModalComponent, {
  title: 'Delete item',
  subtitle: itemName,
  titleIcon: 'Trash',
  footerAlign: 'end',
  data: { message: 'This action cannot be undone.' },
});

ref.afterClosed().subscribe((result) => {
  if (result === true) {
    // proceed with deletion
  }
});
```

`afterClosed()` emits once with the value passed to `close(data?)` and then completes.

### Template approach

Declare `<iris-modal>` in your template and call `open()` / `close()` from a template reference variable. Use `<ng-template irisModalFooter>` (import `IrisModalFooterDirective`) or the legacy `<ng-container irisModalFooter>` (projected via `ng-content`) for footer actions:

```html
<iris-button (click)="modal.open()">Open</iris-button>

<iris-modal #modal title="Confirm deletion" subtitle="This cannot be undone."
  (closed)="onClosed($event)">
  <p>All associated data will be permanently removed.</p>
  <ng-template irisModalFooter>
    <iris-button variant="secondary" (click)="modal.close()">Cancel</iris-button>
    <iris-button variant="danger" (click)="modal.close({ confirmed: true })">Delete</iris-button>
  </ng-template>
</iris-modal>
```

## Typing options

`IrisModalService.open()` supports four combinations of typed data and typed result. Both are opt-in — use only what you need.

### Typed data

Implement `IrisModalContent<D>` on the content component and assign `injectModalData<D>()` to `modalData`. The `data` field in `IrisModalConfig` is then compile-time checked against `D`.

```ts
// content component opts in to typed data
class MyComponent implements IrisModalContent<{ itemId: number }> {
  readonly modalData = injectModalData<{ itemId: number }>();
}

modalService.open(MyComponent, { data: { itemId: 42 } }); // ✅
modalService.open(MyComponent, { data: 'wrong' });          // ❌ compile error
```

Components that do not implement `IrisModalContent` accept any value (or none) for `data`.

### Typed result

Pass `R` as an explicit type argument to `open<R>()` to type the value emitted by `afterClosed()`. The content component calls `modalRef.close(value)` with a matching type.

```ts
// content component
class ConfirmComponent {
  readonly modalRef = inject(IrisModalRef<boolean>);
  confirm() { this.modalRef.close(true); }
  cancel()  { this.modalRef.close(false); }
}

// caller
const ref = modalService.open<boolean>(ConfirmComponent, { title: 'Confirm?' });
ref.afterClosed().subscribe((confirmed: boolean) => { ... });
```

Omit the type argument to leave the result as `unknown`.

### All four combinations

| Data typed | Result typed | Call |
|---|---|---|
| ✅ | ✅ | `open<boolean>(MyComponent, { data: { itemId: 42 } })` |
| ✅ | — | `open(MyComponent, { data: { itemId: 42 } })` |
| — | ✅ | `open<boolean>(SimpleComponent, { title: '...' })` |
| — | — | `open(SimpleComponent, { title: '...' })` |

## Dismissal control

When `dismissable` is `true`, you can control the two automatic dismissal paths independently:

- `closeOnEscape` controls whether Escape closes the modal.
- `closeOnBackdropClick` controls whether clicking the outer dialog surface closes the modal.

## Accessibility

- The native dialog element carries `aria-modal="true"`.
- `aria-labelledby` always points to the generated title id.
- `aria-describedby` is added only when `subtitle` is present.
- The dismiss button label defaults to `"Close"`. Override `closeAriaLabel` when a localised label is needed.
- The component relies on native `<dialog>` behaviour; it does not implement custom focus restoration for template usage.
- `IrisModalService` restores focus to the previously focused element after cleanup.

## API

### IrisModalConfig

| Property | Type | Default | Notes |
|---|---|---|---|
| `data` | `unknown` | `null` | Exposed to dynamically created content through `IRIS_MODAL_DATA`. Type is inferred from the component's `IrisModalContent<D>` implementation when used via the service. |
| `title` | `string` | `''` | Written to the header title. |
| `titleIcon` | `string` | `''` | Renders an icon before the title when non-empty. |
| `subtitle` | `string` | `''` | Adds subtitle text and `aria-describedby` when non-empty. |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Forwarded to the modal's `size` input when defined. |
| `dismissable` | `boolean` | `true` | Controls whether the header close button is rendered and whether automatic dismissal paths are allowed. |
| `closeAriaLabel` | `string` | `'Close'` | Accessible label for the × close button. Localise for non-English UIs. |
| `closeOnEscape` | `boolean` | `true` | Used only when `dismissable` is `true`. |
| `closeOnBackdropClick` | `boolean` | `true` | Used only when `dismissable` is `true`. |
| `hasBackdrop` | `boolean` | `true` | Forwarded to the modal and used by the dialog template to toggle the backdrop class. |
| `footerAlign` | `'start' \| 'center' \| 'end'` | `'end'` | Controls the footer alignment class. |

### IrisModalRef\<R\>

Returned by `IrisModalService.open()`. `R` is the type of the value passed to `close()`.

| Member | Signature | Notes |
|---|---|---|
| `afterClosed()` | `() => Observable<R>` | Emits once with the value passed to `close()`, then completes. Use `firstValueFrom(ref.afterClosed())` for a Promise. |
| `close()` | `(data?: R) => void` | Closes the modal and emits `data` via `afterClosed()`. Call from the content component via `inject(IrisModalRef)`. |
